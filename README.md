## ✅ 2024年上半期 資格取得戦略ドキュメント

### 🎯 ゴール

- 実務で通用する技術証明を固める
    
- "プロマネ資格なし"という弱点を1つの資格で補完
    
- 資格に依存せず、コードや構成の実績も併用して強化する

## ✅ 学習・受験スケジュール（例）

|月|資格|学習・対策内容|
|---|---|---|
|4月|CKAD-JP|Udemy + KillerShellで演習 → 本番受験（JP）|
|5月|CKA-JP|CKADとの差分（ネットワーク / RBAC / etcd）に集中 → 5月中受験|
|6月前半|Terraform Associate|実装ベースで学習 + 試験対策 → GitHubに構成をまとめておく|
|6月後半|HFCP or PMI-ACP|並行しても可。PMI-ACPは時間コントロールでバランス良く取得|
|7月以降|AWS SA（任意）|優先度は低く、リターンが小さいなら無理に取らなくてOK|

## 📝 補足メモ

- CKAD/CKAは今のOperator/Helm学習が完全にリンクしており、資格対策 = 実務力強化になる
    
- HFCPは差別化効果が非常に高く、ブロックチェーン構成における説得力のある証明書
    
- Terraform資格はコードベースで証明できるあなたに最もコスパが良い
    
- PMI-ACPはPMPの代替として“ちょうどいい”難易度と知名度のバランス
    
- AWS SAは「暗記コストが高く、あなたにとってリターンが薄い」。Terraformと実務経験で代替可。
