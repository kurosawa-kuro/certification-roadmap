## 🔍 用語のご説明

### 🔧 Kubernetes（クーバネティス）とは？
Googleが開発した「現代的なITシステム運用の基盤技術」です。
複数のアプリやサービスを、効率よく自動的に起動・監視・復旧する仕組みで、大手企業をはじめ、最新の開発現場でほぼ標準になっています。
→ Kubernetesを扱えると「インフラ運用力」が高いと評価されます。

また、KubernetesはDockerやFargateといった他の技術と比較して、難易度が高く、運用の自由度も増します。
例えば、Dockerはコンテナ技術を使った「アプリ単体の実行環境」ですが、Fargateは「サーバーレスのコンテナ運用」であり、Kubernetesは「コンテナオーケストレーション」を行うため、マイクロサービスの大規模運用を可能にします。
難易度としては、Docker → Fargate → Kubernetesと順番に上がりますが、最終的にはKubernetesを使いこなせることで、より高いスキルと信頼性を証明できます。

### 🔗 Hyperledger Fabric（ハイパーレジャー・ファブリック）とは？
IBMなどが開発した「**企業向けブロックチェーン技術**」です。  
ビットコインのようなパブリック型とは違い、限られたメンバー内でセキュアに履歴を管理できるため、**サプライチェーン管理やトレーサビリティ**に強みがあります。  
→ Fabricを使った開発経験があると、「ブロックチェーン実装経験者」として信頼されます。
