## 🔍 用語のご説明

### 🔗 Hyperledger Fabric（ハイパーレジャー・ファブリック）とは？
IBMなどが開発した「企業向けブロックチェーン技術」です。  
ブロックチェーンには、ビットコインのように誰でも参加できる「パブリック型」と、限られたメンバーで運営する「プライベート型」があります。  
Hyperledger Fabricはプライベート型のブロックチェーンで、限られたメンバー内で**セキュアに履歴を管理**できるため、特に**サプライチェーン管理やトレーサビリティ**に強みがあります。  
→ Fabricを使った開発経験があると、「**ブロックチェーン実装経験者**」として信頼されます。

黒澤はこれまでパブリック型のブロックチェーン（例：ビットコインやEthereum）での実務経験があり、今回は初めてプライベート型である**Hyperledger Fabric**を使用した実務に挑戦します。この挑戦により、より高度な企業向けブロックチェーン開発スキルを証明できます。

---

### 🔧 Kubernetes（クーバネティス）とは？
Googleが開発した「現代的なITシステム運用の基盤技術」です。  
複数のアプリやサービスを**効率よく自動的に起動・監視・復旧**する仕組みで、大手企業をはじめ、最新の開発現場でほぼ標準になっています。  
→ Kubernetesを扱えると「**インフラ運用力**」が高いと評価されます。

KubernetesはDockerやFargateといった他の技術と比較して、難易度が高く、運用の自由度が増します。  
例えば、**Docker**は「アプリ単体の実行環境」ですが、**Fargate**は「サーバーレスのコンテナ運用」であり、**Kubernetes**は「コンテナオーケストレーション」を行い、**マイクロサービスの大規模運用**を可能にします。  
**Docker → Fargate → Kubernetes**と難易度は上がりますが、最終的にKubernetesを使いこなせることで、より高いスキルと信頼性を証明できます。

---

### プライベートブロックチェーンとKubernetesの相性の良さ
Kubernetes（k8s）はシステム全体を自動的に管理し、効率よく運用できるツールです。  
プライベートブロックチェーン（Hyperledger Fabric）は企業内でのデータ管理に使われますが、これには多くのサーバーやサービスを同時に運用する必要があります。

Kubernetesはこれらのサーバーやサービスを**自動的に管理**し、必要に応じて**サーバーを増減**したり、**問題が発生した際に自動修復**を行います。  
これにより、システムが常に安定して動き続けることが保証されます。

**簡単に言うと、Kubernetesはプライベートブロックチェーンの運用を簡単にし、安定させるために不可欠な技術です**。
